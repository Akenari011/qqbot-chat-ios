一个直接连接 QQ 官方机器人 API 的 iOS 聊天客户端。App 内输入机器人 AppID 与 AppSecret，通过 QQ WebSocket 接收消息，不依赖自建服务器。

## 可以做到的功能列表

> 以下是**已实现的功能入口**，即 App 内可以操作到的能力；稳定性与完成度见顶部「半成品」声明。

### 会话管理

- 多会话列表：按最新消息排序、未读角标（静音显示灰色）、置顶
- 会话搜索：按备注名 / 默认名 / 最后一条消息 / 全部历史内容过滤
- 置顶、归档、静音、标记已读、删除会话（左右双向滑动操作）
- 会话资料：自定义**备注名**、自定义**会话头像**、恢复默认头像
- 自动获取群名称（`GET /v2/groups/{openid}/info`）与子频道名称
- 归档会话显示开关、置顶行高亮、会话分隔线

### 消息收发

- **文本**：Markdown 渲染、URL 自动识别为主题色链接、多行输入、草稿按会话保存
- **图片**：最多九张连发、接收缓存、全屏查看（双指缩放 / 双击放大）、保存到相册
- **视频**：选择上传、首帧缩略图、点击播放、保存到相册
- **语音**：录制发送（AAC/m4a）、接收播放、波形与时长显示
- **文件**：选择任意文件发送、接收后通过系统分享打开
- **按钮消息**：渲染 keyboard 按钮、接收 INTERACTION_CREATE 点击、频道内主动发送带按钮消息
- **表情**：表情面板、QQ `<faceType=...>` 标记解析为 emoji
- 单聊、群聊、频道三种场景的消息收发与被动回复（`msg_id` + `msg_seq`）
- 富媒体上传（`file_type` 1 图片 / 2 视频 / 3 音频 / 4 文件）

### 消息操作

- 引用回复（长按「回复」或左滑消息）、引用内容点击跳转（左滑手势当前不稳定，见顶部声明）
- 长按菜单：复制、转发到其他会话、保存图片/视频、删除本地记录
- **撤回**：单聊 / 群聊 / 子频道 / 频道私信四种官方端点，撤回机器人自己 2 分钟内发出的消息
- 失败消息重发、断线 READY 后自动重试
- 频道消息：编辑、置顶/取消置顶、设为/取消公告、点赞回应/取消、查看点赞用户、表情回应徽章
- 消息状态显示（发送中 / 成功 / 失败）、双勾已读标记、日期分组

### 频道能力

- 频道列表、子频道列表、频道成员列表
- 置顶消息列表、日程查看、拉取最近 50 条频道历史消息

### 连接与账号

- AppID / AppSecret 输入，凭证保存在系统 Keychain
- access_token 自动刷新、WebSocket 网关获取与连接
- 心跳 ACK 超时检测、指数退避重连、Gateway Resume、前台恢复强制重连、网络变化监听
- 重新连接、退出登录、清空全部聊天记录
- 设置页显示机器人名称、AppID、连接状态

### 外观与交互

- 主题（跟随系统 / 浅色 / 深色）、正文字体大小
- 聊天背景：纯色 / 渐变 / 自定义背景图片
- 日期胶囊、气泡按内容自适应宽度、渐变气泡与双勾
- 底部标签栏（聊天 / 设置）、滚动最小化、Liquid Glass 输入栏与圆钮
- 点击消息区域或滚动时收起键盘、图片缩放查看器、历史分页「加载更早消息」
- 回到底部按钮、引用跳转、进入会话自动滚动到底部

### 诊断

- 导出日志（连接、token、收发、重连、错误等）、清空日志、查看日志条数

### 平台侧限制（做不到的）

- 群聊主动 @ 提醒：QQ 客户端不会把 `<@openid>` 渲染成蓝色提及，仅支持引用回复
- 单聊 / 群聊历史消息：QQ 官方未提供接口，只能依赖 Resume 补发
- 实时语音 / 视频通话：QQ Bot API 无此能力
- 群头像与成员真实头像：群消息事件不提供该字段，只能手动设置
- 后台推送：无 APNs，锁屏或长时间后台会暂停 WebSocket

## 安装

1. 从 GitHub Actions 下载 `QQBotChat-unsigned-IPA` 产物，解压得到 IPA。
2. 使用侧载工具重签安装，要求 **iOS 26+**、arm64。无签名 IPA 不能由标准 iOS 直接安装。
3. 打开 App，输入机器人 AppID 与 AppSecret，等待状态显示“已连接”。
4. 先在 QQ 给机器人发一条消息建立会话，再在 App 内回复。

请求权限：麦克风（语音消息）、相册写入（保存图片/视频）。

## 当前限制

> 以下列出的是平台能力边界，不是全部 bug。本项目为半成品，**实际使用中还会遇到大量未列出的界面与交互问题**，详见顶部声明。

- 单聊、群聊、频道消息均支持，但频道管理类 API（角色、权限、禁言、论坛、语音房）未接入。
- 单聊/群聊没有官方历史消息接口，断线期间依赖 Resume 补发；频道可手动拉取最近 50 条历史。
- iOS 锁屏或长时间后台会暂停 WebSocket，没有 APNs 推送。
- 「删除」仅删除本地记录；「撤回」会调用 QQ 官方接口撤回机器人自己 2 分钟内发出的消息（单聊、群聊、频道均支持）。
- 发送依赖 QQ 被动回复窗口（由用户最近一条消息触发）。
